# 05. 작업 계획

상태: 기능 범위 및 사용자 가용 시간 확인 전. 일정은 아직 확정하지 않았다.

| 작업 번호 | 요구사항 번호 | 작업 | 담당자 | 선행 작업 | 예상 일정 | 결과물 | 완료 확인 방법 |
|---|---|---|---|---|---|---|---|

## 중간 목표
범위 확정 → 설계 → 핵심 흐름 구현 → 브라우저 테스트·수정 → 배포 검증 → 시연·제출 준비.

## 일정 제약과 위험 대응
- 과제지 표기 마감: 2026년 12월 11일(금) 밤 12시.
- 사용자의 가용 시간을 확인해 테스트·수정·배포 여유를 포함한 일정을 작성한다.
- 위험별 대응과 담당자는 계획 확정 시 작성한다.
