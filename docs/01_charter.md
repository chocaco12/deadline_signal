# 01. 프로젝트 개요

- 프로젝트명: 과제 신호등 (Deadline Signal)
- 핵심 질문: “마감일은 알고 있는데, 지금부터 해도 끝낼 수 있을까?”
- 서비스 방향: 남은 예상 작업 시간과 마감까지 공부 가능한 시간을 비교해 시간 부족을 알려준다.
- 확인된 사실: 사용자가 위 주제와 서비스 방향을 제안했다.
- 배경과 필요성: 실제 경험을 들은 후 작성 예정.
- 목적: 입력한 시간을 바탕으로 마감 전 완료 가능성을 판단하도록 돕는다.
- 목표와 성공 판단 기준: 미정.
- 주요 산출물: 정적 웹앱, 과제 문서 7개, GitHub 저장소, 실행 URL, 1분 시연 영상.
- 포함·제외 범위: 사용자와 협의 예정.
- 제약: HTML/CSS/JavaScript, 로그인 없는 이용, 과제지 표기 마감 2026년 12월 11일(금) 밤 12시.
- 주요 위험: 예상 작업 시간이 부정확하면 판단 결과도 달라질 수 있다.

상태: 주제 선택 완료, 상세 기획 전. 실제 사용자 조사 결과 없음.
