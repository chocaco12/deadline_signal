# 과제 신호등 | Deadline Signal

“마감일은 알고 있는데, 지금부터 해도 끝낼 수 있을까?”

마감까지 필요한 시간과 공부 가능한 시간을 비교해 시간 부족을 알려주는 웹앱을 기획합니다.

## 진행 상태
주제와 첫 버전의 방향(대학생의 과제 하나 시간 비교)을 확정했습니다.
기획서, 가정 기반 사용자 정의와 요구사항 후보를 작성했습니다. 날짜별 가능 시간 입력과 20% 여유 기준의 신호등을 합의했습니다. 실제 사용자 경험 확인, 개별 요구사항의 최종 선정과 기능 구현은 진행 전입니다.
현재 `index.html`은 준비 안내 화면이며 시간 계산 기능은 없습니다.

## 진행 원칙
- HTML, CSS, JavaScript로 정적 웹앱을 만듭니다.
- 실제 경험·관찰과 가정을 구분합니다.
- 요구사항 번호를 후보부터 계획·설계·테스트까지 유지합니다.
- 공개 저장소에는 개인정보, 비밀번호, API 키를 올리지 않습니다.
- 과제 문서 7개는 각 단계의 결정과 확인 결과에 따라 채웁니다.
