# 과제 신호등 | Deadline Signal

“마감일은 알고 있는데, 지금부터 해도 끝낼 수 있을까?”

마감까지 필요한 시간과 공부 가능한 시간을 비교해 시간 부족을 알려주는 웹앱을 기획합니다.

## 진행 상태
주제와 첫 버전의 방향(대학생의 과제 하나 시간 비교)을 확정했습니다.
기획서, 가정 기반 사용자 정의, 요구사항 후보, 최소 버전 범위, 작업 계획과 화면 설계를 작성했습니다. 날짜별 가능 시간 입력과 20% 여유 기준의 신호등을 합의했고 REQ-01~08을 구현했습니다. 로컬 브라우저와 공개 GitHub Pages 주소에서 핵심 흐름을 확인했습니다. 실제 사용자 경험 확인과 시연 영상·e-class 제출은 남아 있습니다.
